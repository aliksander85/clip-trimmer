# PROMPTS — Clip Trimmer

Один промпт — одна задача из `SPEC.md`, раздел 10.

## Как работать

1. Перед каждой задачей `/clear`, потом `/model <модель>` из таблицы.
2. Для задач с пометкой **plan** включить plan mode (Shift+Tab), прочитать план, поправить, потом разрешить код.
3. После задачи: смотришь дифф, запускаешь UI, коммитишь сам.
4. Агент упёрся в одно и то же дважды — `/clear` и тот же промпт с короткой заметкой, что не получилось. Не тянуть длинный контекст.

### T4 — Воркер: метаданные · Opus · plan

```
Задача T4 из SPEC.md. Читай разделы 5.4, 5.5 (пункты 1–3) и 6.

Сделай lib/media/protocol.ts (все типы из 5.4, включая экспорт), workers/media.worker.ts и app/composables/useMediaWorker.ts.

В плане опиши: как достаёшь description, как считаешь fps, что делаешь при файле без видеодорожки.

Проверка: lint, typecheck, test. Вручную: длительность, разрешение и кодек в UI; ошибка на не-MP4; ошибка на HEVC-файле, если такой есть.
```

### T5 — Миниатюры · Opus · plan

```
Задача T5 из SPEC.md. Читай разделы 5.5 (пункты 4–8), 5.4 и 7.

1. lib/media/thumbnails.ts: pickKeyframes(slotTimes, keyframeTimes) — для каждого слота ближайший ключевой кадр не позже времени слота, результат сгруппирован по кадрам. Тесты: дубли, слот раньше первого ключевого кадра, один ключевой кадр на всё видео.
2. Воркер: собрать сэмплы, выбрать ключевые кадры, декодировать только их, в output — createImageBitmap с resizeHeight, сразу frame.close(), отправка thumb с transfer. Для нескольких слотов одного кадра — отдельный bitmap на каждый. releaseUsedSamples, decoder.close() при done, cancel и ошибке.
3. Главный поток: setThumb в стор; bitmap с устаревшим requestId — сразу close().
4. Только в dev-режиме: счётчики открытых VideoFrame и выданных ImageBitmap, вывод в консоль при done и при reset.

В плане опиши порядок событий от appendBuffer до последнего thumb и все места, где освобождаются ресурсы.

Проверка: lint, typecheck, test. Вручную: видео на 1–2 минуты — все миниатюры за 2 с или быстрее; после трёх загрузок подряд счётчики не растут.
```

### T6 — Отрисовка Canvas · Sonnet · plan

```
Задача T6 из SPEC.md. Читай разделы 5.3 и 7.

Сделай lib/timeline/renderer.ts (drawTimeline — чистая функция, слои строго в порядке из 5.3), app/composables/useTimelineRenderer.ts (canvas, devicePixelRatio, ResizeObserver, цикл requestAnimationFrame с dirty-флагом) и TimelineCanvas.vue.

Число слотов считается через thumbSlots из geometry.ts. При изменении ширины меньше чем на 20% новые миниатюры не запрашиваются — имеющиеся растягиваются (раздел 6).

Взаимодействие мышью пока не нужно — это T7. Hover-состояние в RenderState оставь, но не подключай.

В плане: что ставит dirty-флаг и когда цикл rAF останавливается.

Проверка: lint, typecheck, test. Вручную: чёткая картинка на retina; ресайз окна; в Performance в покое нет кадров отрисовки.
```
